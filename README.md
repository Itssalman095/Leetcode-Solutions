## 📌 About

This repository is **automatically updated** every time I submit an accepted solution on [LeetCode](https://leetcode.com/), thanks to the [LeetHub v2](https://github.com/arunbhardwaj/LeetHub-2.0) Chrome extension. No manual copy-pasting — every accepted solution is pushed here in real time, complete with:

- ✅ Problem statement (as a `README.md` inside each problem folder)
- ✅ My solution code
- ✅ Notes/runtime & memory stats (where available)

## 🗂️ Structure

Each solved problem gets its own folder, organized like this:

```
├── 1-two-sum/
│   ├── README.md
│   └── two-sum.js
├── 2-add-two-numbers/
│   ├── README.md

```
